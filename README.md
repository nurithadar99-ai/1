# אַלּוּף הַפֹּעַל 🎯
### משחק תרגול והכנה אישית לבגרות בלשון עברית (כיתה י"א) • תיכון ברנר

אפליקציית ווב אינטראקטיבית, חווייתית ומותאמת אישית לתרגול פרק **מערכת הפועל** לקראת מבחן הבגרות בלשון עברית.

---

## ✨ מאפיינים מרכזיים

1. **אבחון והתאמה אישית חכמה (Adaptive Engine):**
   - **שלב אבחון:** התלמיד מתחיל עם פעלים מכל 7 הגזרות הנכללות במבחן.
   - **דוח משוב אישי:** מפה מפורטת של נקודות חוזק ונושאים לחיזוק (עם אחוזי שליטה ופסי התקדמות).
   - **אימון מותאם אישית:** המערכת מקצה פעלים בעלי משקל גבוה יותר בדיוק בגזרות שהתלמיד צריך לשפר, ומתעדכנת בזמן אמת!

2. **ניתוח דקדוקי מלא לפי דרישות הבגרות:**
   - **שוֹרֶשׁ:** הקלדה ידנית עצמאית של אותיות השורש (ללא בחירה מרשימה סגורה), כולל נרמול חכם (תמיכה במקפים, גרשיים, נקודות ורווחים).
   - **בִּנְיָן:** בחירה אינטראקטיבית מתוך 7 הבניינים: פָּעַל (קַל), נִפְעַל, פִּעֵל, פֻּעַל, הִפְעִיל, הֻפְעַל, הִתְפַּעֵל.
   - **זְמַן:** עָבָר, **בֵּינוֹנִי** (במקום הווה, לפי המינוח הרשמי בבגרות), עָתִיד, **צִוּוּי**.
   - **גּוּף:** מדבר (אני), מדברים (אנחנו), נוכח (אתה), נוכחת (את), נוכחים (אתם), נוכחות (אתן), נסתר (הוא), נסתרת (היא), נסתרים (הם), נסתרות (הן).
   - **שֵׁם פֹּעַל:** הקלדה ידנית עצמאית (למשל: לִכְתֹּב, לְהִתְכַּתֵּב, לָרֶדֶת).
   - **שֵׁם פְּעֻלָּה:** הקלדה ידנית עצמאית (למשל: כְּתִיבָה, הִתְכַּתְּבוּת, יְרִידָה).

3. **דיוק לשוני מלא לפי כללי האקדמיה ללשון העברית:**
   - כל הפעלים מנוקדים בקפידה בניקוד מלא ומדויק.
   - **כלל נע"ו/י:** אות השורש האמצעית בעי"ן הפועל היא **וָ"ו** (למשל: קו"ם, רו"ץ, בו"ן, שו"ב), **למעט ששת שורשי היו"ד:**
     - **רִי"ב**
     - **שִׁי"ר**
     - **גִּי"ל**
     - **שִׂי"ם**
     - **שִׂי"ח**
     - **קִי"א**
   - משוב ממוקד ומיידי אם תלמיד מתבלבל בין ו' ל-י' בגזרת נע"ו/י!

4. **גזרות הנכללות במאגר:**
   - **שְׁלֵמִים** (פָּתַחְנוּ, תִּשְׁמְרוּ, מַסְבִּירָה, כִּתְבוּ!...)
   - **מְרֻבָּעִים** (פִּרְסַמְתֶּם, מִתְבַּלְבֵּל, עַדְכְּנִי!...)
   - **חפ"ן** - חסרי פ"נ (יַפִּיל, הַסִּיעִי!, מַבִּיטִים, תִּתֵּן...)
   - **נל"י/ה** - נחי ל"י/ה (בָּנוּ, תִּקְנִי, קַוֵּה!, עֲנֵה!...)
   - **נל"א** - נחי ל"א (מָצָאתִי, תִּקְרְאוּ, קְרָא!, מִלֵּאתָ...)
   - **נפ"י/ו** - נחי פ"י/ו (הוֹרִיד, תֵּשְׁבוּ, נוֹלַדְתִּי, שֵׁב!, רֵד!...)
   - **נע"ו/י** - נחי ע"ו/י (יָשִׁירוּ, רַבְתֶּם, שִׂימִי!, הֵקַמְנוּ, מְבִינָה, רוּצוּ!, קוּם!...)

5. **גיימיפיקציה ועיצוב:**
   - נקודות ניסיון (XP), רצף הצלחות (Streak), אפקטים קוליים (Web Audio API), וחגיגות קונפטי.
   - ספר כללי הבגרות נגיש בלחיצת כפתור בכל שלב.
   - התאמה מלאה למחשבים נייחים, טאבלטים וטלפונים ניידים.
